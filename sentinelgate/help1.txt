Lobster Trap is a security middleware for AI agents.
It sits between an AI agent and the LLM, inspecting every prompt and
every output using deep prompt inspection ΓÇö regex-based metadata extraction
evaluated against programmable firewall rules.

Usage:
  lobstertrap [command]

Available Commands:
  completion  Generate the autocompletion script for the specified shell
  help        Help about any command
  inspect     Inspect a single prompt and show extracted metadata
  serve       Start the Lobster Trap reverse proxy
  test        Run built-in test prompts against the policy
  version     Print the version

Flags:
  -h, --help   help for lobstertrap

Use "lobstertrap [command] --help" for more information about a command.
