Start the HTTP reverse proxy that inspects prompts and responses using deep prompt inspection.

Usage:
  lobstertrap serve [flags]

Flags:
      --audit-log string   Path to audit log file (default: stderr)
      --backend string     Backend LLM server URL (default "http://localhost:11434")
  -h, --help               help for serve
      --listen string      Address to listen on (default ":8080")
      --no-dashboard       Disable the real-time dashboard
      --policy string      Path to policy YAML file (default "configs/default_policy.yaml")
